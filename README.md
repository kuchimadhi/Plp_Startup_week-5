# SmartyBiz — Startup Pitch Deck

A responsive, browser-based pitch deck for **SmartyBiz**, a business intelligence and customer-engagement concept for small businesses. Built from the supplied SmartyBiz presentation.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Presentation controls
- **Next / previous:** click the arrow controls.
- **Keyboard:** use ← / →, Page Up / Page Down, Home, or End.
- **Touch:** swipe left or right on mobile.
- **Present:** use the Present button to enter a distraction-reduced presentation view.

## Files
- `index.html` — 13-slide deck content and structure.
- `style.css` — responsive layout, typography, slide visuals, and animations.
- `script.js` — slide navigation, progress, keyboard controls, and presentation mode.

## Content note
Market and financial figures are reproduced from the source pitch. The source lists monthly revenue as $6,500 while the listed package totals ($3,750 + $2,500) equal $6,250; the deck flags this discrepancy for confirmation.
